# Ваши заметки

Создавайте заметки кнопкой **«Новая заметка»**. Папки открываются двойным кликом, заметки — одним.

Над списком есть переключатель **«Вид»**: список, плитки или крупные значки. Три кнопки в верхней строке скрывают и возвращают панели. Потяните вертикальную границу, чтобы изменить их ширину. Правая кнопка мыши по папке или пустому месту открывает меню создания заметок и папок.

## Копирование команд

```bash
git status
```

Нажмите **«Копировать»** в углу плашки. Команда попадёт в буфер обмена и не будет запущена.

Поиск — **Ctrl+K**, сохранение при редактировании — **Ctrl+S**.
