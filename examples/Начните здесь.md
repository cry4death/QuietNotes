# Ваши заметки

Создавайте заметки кнопкой **«Новая заметка»**. Папки открываются двойным кликом, заметки — одним.

Над списком есть переключатель **«Вид»**: список, плитки или крупные значки. Кнопка рядом скрывает область просмотра, чтобы показать больше папок.

## Копирование команд

```bash
git status
```

Нажмите **«Копировать»** в углу плашки. Команда попадёт в буфер обмена и не будет запущена.

Поиск — **Ctrl+K**, сохранение при редактировании — **Ctrl+S**.
